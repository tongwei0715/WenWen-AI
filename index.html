wenwenai 常见问题

                        
关于 问问Ai 的常见解答

                    

                

                

                    

                        不用电脑，手机自己真的能跑 Python、读账单做表格吗？
                        
是的。问问Ai 全能工作站版在应用内部完整打包了免 Root 的 Ubuntu 24.04 与 Node.js 24 运行环境，无需额外安装配置 Termux，手机自己就能在本地执行 Python 脚本、解析 PDF/Word/Excel 文档并生成报表。

                    

                    

                        开启「手机屏幕操控」安全吗？遇到密码和支付页面怎么办？
                        
问问Ai 严格遵循「看懂屏幕再动手、关键一步先问你」的安全边界：日常点按、输入、滑动均可代劳，但遇到银行、支付、密码输入与系统权限设置时会自动停下交还给你。在支持 Shizuku 的设备上还可开启「后台不打扰模式」，在独立虚拟屏运行而不抢占你当前画面。

                    

                    

                        全能工作站版（v1.1.0）与轻量操控版（v0.3.11）有什么区别？可以同时安装吗？
                        
可以同时安装共存！全能工作站版（包名 cn.wenwenai.app）内置完整 Ubuntu 容器、实时语音通话、酒馆玩法包、问问仔桌宠与远程电脑连接；轻量操控版体积更小（96.5 MB），免解压直接内嵌 Bionic Node.js 与 18 款主流 App 操控手册。

                    

                    

                        新版发布后怎么升级？原来安装的插件和对话会丢失吗？
                        
不会丢失。问问Ai 全系使用同一枚永久证书签名，升级时只需在「设置 › 关于 问问Ai › 检查更新」内直接更新，或从官网下载最新 APK 直接覆盖安装，所有对话记录、API 密钥以及你在 Linux 容器内安装的 apt/npm/pip 工具包都会完整保留。
