一个助手，一支专家团

不只是对话工具，而是可并行运作的数字生命体

多用户多 Agent

一人管理，全家共用。内置专家库与专家市场，按场景一键切换专业角色。

IM 全通道

飞书、钉钉、QQ、微信、企业微信，或 HTTP / SSE / WebSocket API，随时随地对话。

隐私优先

JWT 多用户隔离、工具审批、Shell 防护与敏感信息脱敏。对话与数据只留在本地。

Connector 生态

一键接入腾讯文档、会议等常用服务，OAuth 与 MCP 网关轻松扩展能力边界。

记忆与知识库

可迁移的记忆系统 + 基于文档的 RAG 检索，让回答锚定你的私有知识。

开发者增效

ACP 双向集成 IDE 与终端 AI，浏览器 AI+ 与远程桌面搞定网页自动化。

三步，跑起来

单进程启动 Web 控制台、CLI、IM 通道与定时任务

# 克隆项目
$ git clone https://github.com/tongwei0715/WenWen-AI.git
$ cd WenWen-AI && bash scripts/install.sh --from-source
# 初始化并启动
$ wenwen init && wenwen run
# 打开 http://127.0.0.1:8088 开始使用
